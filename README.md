## <img src="assets/section-projects.svg" alt="What I've Worked On / Projects" width="30">

### [Campus Tag – Lost & Found System](https://github.com/Rehman0986/Campus-Tag-Lost-and-Found)

**Python · Django · Django REST Framework · Next.js · PostgreSQL · JWT · QR Codes**

- Developed a multi-tenant campus lost-and-found platform where students and staff can register belongings with unique QR codes.
- Implemented QR-based public finder pages that let finders contact item owners without exposing private contact details.
- Built role-based access for Super Admin, customers, and public finders, with item, organization, subscription, and report management.
- Integrated interactive maps using Leaflet and OpenStreetMap, including location search, GPS location, and map pin selection.

### [Facial Recognition Attendance Management System](https://github.com/Rehman0986/facial-recognition-attandance-system-web-based)

**Python · Flask · OpenCV · PostgreSQL**

- Designed and implemented a web-based automated attendance system using facial recognition to replace manual attendance workflows.
- Built backend APIs for user registration, face-embedding storage, and attendance marking with PostgreSQL persistence.
- Integrated OpenCV and deep-learning-based face recognition workflows to compare captured images with stored embeddings.
- Generated PDF/CSV reports for attendance analytics and administrative use.

### [Ecommerce Website – Full-Stack Marketplace](https://github.com/Rehman0986/Ecommerce_website)

**Python · FastAPI · React · SQLite · JWT**

- Built a full-stack e-commerce marketplace with a React storefront and FastAPI backend, supporting product browsing and shopping workflows.
- Implemented product catalog management, categories and subcategories, product variations, image uploads, filtering, and reviews.
- Developed cart, checkout, order lifecycle tracking, coupon validation, and configurable payment-method management.
- Created an admin-only back office with protected management screens, JWT-based authentication, and SQLite database migrations.
